Honest data boundary

The configured NASDAQ files do not provide point-in-time exchange membership, verified delisting returns, permanent security identity, ticker-change history or known corporate-action adjustment provenance. Therefore a file ending early is right-censored with unknown delisting status; it is never silently treated as a −100% return, a zero return, or the acquiring company. Results describe the stored OHLCV universe and cannot be called survivorship-free exchange history.

Exact outcome semantics

OriginThe matched episode's stored close at its cutoff. This is a descriptive reference price, not an assumed executable fill.
Horizons5, 10, 20, 40, 60 and 126 subsequent observed stock sessions. Expected-session gaps are detected against the exact benchmark calendar and censored rather than stretched silently.
ReturnsClose return, gross benchmark-relative return, MFE, MAE and ATR-normalized excursions. No calendar-day approximation or benchmark forward fill.
Primary eventWithin 20 sessions, first touch of origin close +2 ATR versus origin close −1 ATR. If both are first touched in one daily bar, the event is ambiguous and excluded from the directional denominator.
ATRSimple mean of 20 true ranges ending at the origin; the first true range requires the preceding close. No future value enters ATR.
PathsStore every observed future step through 126 with raw-return, benchmark-relative and ATR-normalized coordinates. Partial paths remain auditable but never count as complete horizons.
EmbargoA historical match contributes at horizon H only if the complete H-session path was already observable by the query cutoff. An early barrier touch does not shorten this embargo.

Build once, reuse safely

The 65,400 query-match links can repeat the same historical episode. T14-09 first deduplicates by episode and source fingerprint, loads each symbol once per stable partition, computes each future once, then joins immutable outcomes back to query/rank. This improves speed without changing a value. Raw query links, unique episode outcomes and future paths remain separate artifacts.

Final user-facing output

  1. The current chart and its exact observation cutoff.
  2. Twenty closest earlier charts with component explanations and immutable ranks.
  3. For each analogue, the actual normalized future path, return/MFE/MAE, barrier route and censor/data-quality status.
  4. A descriptive distribution with raw and effective sample sizes, visible failures and uncertainty.
  5. An explicit abstention when history is too sparse, dependent, contradictory, novel or poorly covered.

This answers: “Among historical states that genuinely resemble this one, what happened next?” It does not answer: “What must happen next?”
