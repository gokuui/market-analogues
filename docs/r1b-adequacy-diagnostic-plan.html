R1-B plan: is recurrence specific or generic?

Decision to make

R1-A found that the sealed NASDAQ neighbor graph is much more concentrated than its independent-query random-priority causal baseline. R1-B must determine whether recurrent episodes are specifically close to coherent groups of charts—consistent with reusable historical archetypes—or are generic hubs selected across unrelated charts.

What R1-B cannot decide: prediction, profitability, buy/sell action, trader pattern names, or final strong/weak/insufficient adequacy labels. It may publish structural diagnostics and, only if its strict conditional gates pass, the phrase structurally localized recurrence. Retrieval stays byte-identical.

Corrections frozen before implementation

  • No causal reciprocity metric. Historical-only retrieval is a directed acyclic graph. If older A is legal for later B, later B is future information for A. Zero mutual directed edges is structurally required, not a retrieval failure. Symmetric distance may be computed offline only as a clearly labelled geometry diagnostic.
  • Top-20 reordering is not set stability. Removing a score component within the stored top 20 cannot reveal candidates that should enter from outside. True neighbor-set stability requires a new certified search.
  • Component ablation is not channel ablation. The production price DTW jointly contains close, ATR, volume-z and relative-price paths. Zeroing a named score component does not remove all related input channels.
  • Packed stores are bounds, not exact representations. Exact variant scores must be reconstructed from causal source prefixes and independently certified.
  • Nearby cutoff has two meanings. Production-risk-set stability allows eligibility to evolve; common-risk-set stability fixes eligibility to the earlier cutoff. They are reported separately.

Execution sequence

B0-01 — Freeze and bind the reuse-only audit

Bind the R1-A preregistration/result/full-integrity receipt, shadow registry/case manifest, walk-forward registry, effective query-symbol-excluded link manifest, packed generation and every code/test hash. Enumerate permitted input paths; outcome, evidence-card, prediction, Stockbee and forward-return stores are forbidden.

Test before proceeding: reconstruct every upstream digest and case/link count; verify all 3,270 current and 3,936 historical query identities; prove no outcome path was opened; require create-only atomic output.

B0-02 — Run a support-only matching pilot

Use only causal eligibility memberships and nuisance covariates—never R1-B distances or statistics—to choose the narrowest exact matching cells that give adequate randomization support. Start with 21-session cutoff bin × A/B query tier × liquidity tertile × point-in-time volatility tercile × context-availability. For the later structure-sensitive null, test deterministic coarse partition counts K={8,12,16} and freeze the largest supported K; merge cells smaller than 30 by a deterministic nearest-cell rule.

Support gate: each tested recurrent episode needs at least 4,096 distinct feasible matched sets; at least 90% of cohort episodes and 90% of recurrent links must pass. If no frozen option passes, publish insufficient-null-support; never broaden cells after observing R1-B statistics.

B0-03 — Reuse exact results for local geometry

For all current queries, report d1, d5, d10, d20, normalized gaps/spans, component contribution/dominance and within-top-20 component reordering. Use the 1,152 walk-forward development queries to form outcome-blind empirical peer references matched on the frozen nuisance cells. Call these empirical references, not a generative null.

Test before proceeding: independently reconstruct source-case seals, totals from frozen weights and component values, rank order and all peer-cell membership. Preserve every unsupported query in the denominator and label it explicitly.

B0-04 — Reuse historical queries for production-set cutoff stability

Measure exact episode-ID and symbol Jaccard, rank-biased overlap and distance drift for the 65 same-symbol pairs within 40 calendar days and the 122 within 65 days. This is production-risk-set stability: representation and eligibility both evolve. No causal reciprocity statistic is produced.

Test before proceeding: use observed sessions for temporal ordering; bind both source sets; reconstruct effective query-symbol exclusion; report the pair inventory and all zero-overlap cases rather than filtering them.

B0-05 — Shared-priority sensitivity

Repeat the R1-A concentration comparison with priorities shared across queries, rather than independent for every query. Freeze two nulls before execution: one global episode priority and one hierarchical symbol-then-episode priority. Both retain each query's exact causal risk set and the production cap-three/inclusive-overlap selector. This tests whether R1-A concentration can arise from shared ordering alone.

Test before proceeding: exhaustively validate the shared sampler on tiny enumerated universes; compare its selector with production; require serial/12-core identity; reconstruct every null replicate and result table. Report this as sensitivity to a specified null, never as a probability that hubness is harmful.

B0-06 — Independent integrity verification

A separate verifier reconstructs all frozen hashes, identities, metrics, support decisions, random replicates and HTML. It must refuse any future/outcome access, altered neighbor identity, missing/duplicate query, non-finite metric or partial output.

B0 output: raw structural evidence and a go/no-go decision for the bounded exact POC. No adequacy label is authorized.

B1 — Twenty-four-query exact multi-variant POC

Select 24 queries outcome-blind from the existing warmup/baseline-seed fold, stratified across tier, liquidity and era, excluding later locked validation/final cases. In one shared packed pass per base query, maintain safe frontiers for baseline, score-component ablations, explicitly defined true-channel ablations, valid deterministic OHLC perturbations and observed-session cutoff shifts. Materialize the union of exact candidates once, score all variants and close each certificate independently.

Test before proceeding: baseline must reproduce its frozen top-20 exactly; every variant must have a unique identity binding base query + contract + seed + representation digest; bounds must be proven safe for that variant; common-risk-set and production-risk-set stability must be separate; scalar and 12-core results must match. Stop at 24 if correctness, latency or certificate closure fails; expand to about 96 only after a frozen pass.

B2 — Conditional recurrent-episode specificity

Include every episode with R1-A inbound count at least five—the threshold is fixed because four was R1-A's preregistered null p99. For episode e, define Ue as all queries where it is causally eligible and Qe as queries that actually selected it. Test equal-episode primary aggregates for query cohesion, query-difficulty-normalized candidate specificity and breadth across frozen structure cells. Market-context-excluded chart structure is primary; full distance and market-context-only are mandatory secondary views.

Use 4,096 deterministic conditional-randomization replicates. N0 preserves exact causal exposure, recurrence count and nuisance-cell composition. N1 additionally preserves the support-pilot's frozen coarse query-structure composition. Sampling is uniform without replacement within each cell and includes the observed selections in its feasible universe.

Limited scientific gate: under strict N1, market-excluded cohesion and specificity each require one-sided p≤0.01 plus frozen practical effect sizes; directions must also pass N0, hash-even/odd query splits and leave-one-episode-out influence checks. Context-only significance cannot substitute. Low support or instability yields unresolved.

Even then, the card remains descriptive until a separately frozen prospective outcome study demonstrates predictive value.
