Setup analogues: plan v3

market-analogues · 2026-09-27 · This plan follows the P0–P2 results (experiments/p2/P2_RESULTS.md). It is based on four literature reviews: evidence on setup events, similarity within a setup type, catalyst data, and evaluation method. It supersedes the v2 plan's direction. Nothing here has been run yet.

Reframing. The old question was "Which stocks will rise, judged from their whole chart?" That is now answered no.

The new question is "This stock just had a setup: a breakout from a base, a gap of at least 2σ, a +4% burst, or a new 52-week high after consolidation. Among past setups of the same type that looked like this one, what happened, and which ones worked?"

This is the owner's analogue idea, applied only where patterns plausibly matter. It is scored by payoff in R after costs, against matched controls and a simple model.

1. What the research says

Base rates:

  • Unconditioned breakouts are close to break-even.
  • Practitioner setups (EP and breakout) have a negative median. All their profit sits in a fat right tail.
  • Breakout failure rates roughly doubled from the 1990s to the 2000s, so expect edges to decay.
  • Meta-labelling usually lifts precision by only a few points. Its value is in sizing and in skipping bad-regime setups.

India:

  • The 52-week-high effect is present, and India showed the strongest post-new-high returns in one multi-country study.
  • Big moves in large caps reverse, and so do extreme opening moves.
  • There is no rigorous study of returns after an NSE upper-circuit hit. Our own circuit-lock finding makes locked entries the first thing to exclude.
  • Stocks added to surveillance lists (ASM) underperform afterwards.

Similarity within a setup type

  • Condition first, then match. This is the core of two-step analogue methods in weather forecasting, and Lo–Mamaysky–Wang also found pattern-conditioned return distributions are informative. However, supervised trees usually still beat analogues on the same data (Taillardat 2019: analogues −12% CRPSS, quantile forests +10%). Expect analogues to be mainly an explanation layer.
  • The data format matters more than the model. Scale each event window to its own base high and low (the Jiang–Kelly–Xiu ablation).
  • Cheapest strong sequence features: MiniRocket, MultiRocket+Hydra and QUANT (random convolutional kernels; minutes on CPU; best in the 2024 time-series benchmark). Test them as extra GBM features. With 10k–200k events, a GBM on good features should match or beat deep models.
  • Outcome-defined neighbours for free: two events are similar if they fall in the same GBM or quantile-forest leaves. This is "similar setups → similar outcomes" learned directly.

Information beyond the chart

  • Earnings dates are the biggest single addition, and they are free.
    • US: SEC EDGAR 8-K Item 2.02 filings, from 2004, including delisted companies, with the acceptance time (so pre-market or after-close is known).
    • NSE: results broadcast timestamps from NSE and BSE filings.
    • EAR, the gap and volume can then be computed from existing OHLCV.
    • Caveat: US post-earnings drift has largely gone in non-microcaps since about 2006–2016. Test by era.
  • Group strength can be built at near-zero cost once there is a sector map: SIC codes from EDGAR for the US, NSE industry codes plus the sector indices already in Azure for India.
  • Later additions: EPS and sales acceleration from XBRL (US from 2009 onward), NSE delivery % and bulk deals, and surveillance lists. Surveillance-list history is hard to rebuild, so start archiving it now.
  • Deferred: analyst revisions and short interest.

2. Design

Setup events (causal, fixed before any outcome is computed)

EventDefinition at close t (entry at open t+1)
GAP2S(ln Lt − ln Ht−1)/σ252 ≥ 2, tiered 2–4σ and >4σ
BASE_BOClose above the maximum high of the prior 20–60 sessions; base depth ≤ 35%; prior uptrend (close above a rising SMA50, or ≥ 30% gain over 63 days)
BURST4C/C−1 ≥ 1.04, volume above the previous day's, plus a volume/turnover floor
NH52_CONSClose at a 252-day high, with the previous 252-day high set at least 20 sessions earlier

VCP is a feature of BASE_BO, not a separate event. Each event type has a 20-session cooldown per stock. Overlapping events are tagged, not deduplicated away.

Outcome labels (fixes from P0–P2)

  • Fillability. An NSE entry bar locked at the upper circuit cannot be filled. An exit on a lower-circuit-locked bar rolls to the next unlocked open. Every result reports both realistic R and filled-anyway R; the difference is the phantom share.
  • Ordinal R-ladder with the stop-out class split into a clean −1R stop and a gap-through loss. Realized R is never clipped at −1.
  • Costs in R: cost_R = round-trip % ÷ (R/price), using spreads from Abdi–Ranaldo / Corwin–Schultz, with a floor of 5 bp (US) or 10 bp (NSE), plus a square-root impact term.
  • Delistings: an exit for poor performance gets −30%, with −55% as a stress test. An exit by merger closes at the last price.
  • Universe: price ≥ $2 (NASDAQ) or ≥ ₹20 (NSE), a minimum dollar volume floor, and at least 250 bars of history.

Controls and baselines (for every event)

  • C1, matched non-event: same date, nearest match on size or ADV, ATR%, 120-day momentum and 20-day return, run through the same exit policy. This separates the value of the setup from the value of the exit policy.
  • C2: a random non-event date on the same stock.
  • Base rate: the ladder distribution for each event type and year.
  • B1: a GBM on about 10 obvious features. The main question is whether a candidate beats B1.
  • B0: random selection among the day's events, used in the portfolio simulation.

3. Evaluation protocol

  • Unit of inference: the weekly cohort, not the individual event. Setups cluster heavily in the same week, so each week's mean paired difference is one observation. Use Newey–West with lag ≥ 4, or a stationary bootstrap by week. Report the design effect, which is how much the clustering inflates the variance.
  • Primary metric, for each event type × market: the incremental net expectancy of the top quintile under the candidate, minus the top quintile under B1, measured within each event-week.
  • Secondary metrics: ranked probability skill (RPSS) vs the base rate and vs B1, reliability/ECE, the within-event-day rank correlation, monotonic expectancy by decile, and the tail share of total R.
  • Portfolio simulation (final gate): each day, rank the fillable events, fill only free slots, risk 0.5–1% per 1R, cap position size by ADV, and don't carry unfilled signals forward. Run the identical simulation with the candidate ranking, the B1 ranking and random selection (B0).
  • Power: the standard deviation of R is about 1.3. With clustering and correction for multiple tests, detecting +0.2R needs about 3,400 events per arm per test; +0.1R needs about 13,600. Event counts per type are measured first (E0). An underpowered test is dropped or pooled before looking at results.
  • Multiple testing: preregister the family (about 4 events × 2 markets × a few candidates). Use Romano–Wolf StepM or Holm correction across it, SPA for "does anything beat B1", DSR and PBO for portfolio Sharpe ratios, and t > 3 for exploratory claims. The trial count comes from an automatic log.

Holdout

  • Development on NASDAQ; confirmation on NSE (survivors only, circuit rules on).
  • Primary vault: about 20% of NASDAQ tickers sealed by hash, across all years. No event-conditioned work has touched them.
  • Time vault: origins from 2025-09 onward (NASDAQ to about 2026-02). NASDAQ 2023 to 2025-08 was seen in aggregate by WF-04 and P0/P1, so it is not treated as sealed time.
  • Each vault is opened once per event type, with a frozen model and a preregistered test.

4. Phases and stop rules

  1. E0 — Events and realistic labels (2–3 days). Build the four detectors, fillable and gap-aware labels, costs, the delisting rule and the C1/C2 controls. Report event counts by type, year and market, and compare them with the power requirement. Report base rates, including the share of events reaching +2R before −1R, and the phantom share on NSE.
  2. E1 — Does any setup type have an edge? (1 day). G1 against matched controls, on NASDAQ development data. Stop rule: if no setup type passes G1 net of costs, setups are not where the edge is. Record that and stop.
  3. E2 — Within-setup discrimination (2–3 days). B1 vs M1, then A0/A1 analogues (neighbour IC vs a same-type, same-date-bucket null, CRPS/RPS, kNN vs the model head), then M2 MiniRocket. Stop rule: if nothing passes G2 for any setup type that survived E1, stop the chart-based track.
  4. E3 — Catalyst layer (3–4 days). Add EDGAR 8-K earnings dates for NASDAQ, and test earnings setups against no-news setups (the Chan/Savor split). Add the NSE results dates after that.
  5. E4 — Portfolio simulation, capacity and vaults. G5–G7 on NASDAQ, then NSE confirmation with circuit rules.
  6. E5 — Only if something passes: a viewer showing, for a live setup, the predicted R-ladder, 10–20 outcome-aligned analogues (A0) with their charts and outcomes, and the caveats.
Honest expectations
  • Every review points the same way: setup shape carries little. Event context carries some: gap size, volume, catalyst, same-day count and market state. So does catalyst information.
  • The most likely positive result is a modest within-setup ranking (a few tenths of R per trade at the top quintile), concentrated in earnings setups and smaller liquid names.
  • Analogues will most likely serve as explanation rather than as the ranking signal.
  • The stop rules at E1 and E2 keep the cost of a negative answer to about a week.
