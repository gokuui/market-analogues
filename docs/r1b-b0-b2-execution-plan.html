Freeze-ready B2 core

Population and unit

  • Primary set S: the exact 357 episodes passing verified K8 support; publish IDs and digest before geometry. Retain all 369 episodes and 2,865 links as disclosure denominators.
  • Episode is the analysis unit. Every confirmatory aggregate is an equal-episode mean; never pool links or weight by recurrence.
  • For every episode bind Ue (all causally eligible query IDs), Qe (observed selecting IDs), m_e, and exact N0/N1 occupied-cell counts.

Primary geometry

Use the sealed 141-value market-excluded query representation. Apply the exact v3 empirical midrank transform. For N query values, map candidate value x with doubled rank m: if x equals a query tie block at one-based positions a…b, m=a+b; if exactly L query values are smaller and x lies strictly between distinct query values, m=2L+1. Then z=clip((m-(N+1))/(N-1),-1,+1); below/above the query range therefore maps to −1/+1. Freeze all matrix digests before membership/statistic code.

delta_chart(a,b) = sqrt(mean_j((z_aj-z_bj)^2)) over all 141 columns, without extra weights or whitening.

Co-primary statistics

  1. Query cohesion: for episode e, mean pairwise delta_chart among queries in the selected set; aggregate by equal-episode mean. Lower is more localized.
  2. Candidate specificity: within each query, midrank delta_chart(q,e) among all causally eligible recurrent cohort episodes; scale to (rank−0.5)/n, average within episode, then equal-weight episodes. Lower is more specific.

Breadth uses effective K8 cell count exp(−sum p log p), normalized by min(8,m_e). N1 fixes the K8 count vector, so breadth has no N1 p-value and cannot enter its gate; report it under N0 only.

Conditional randomization

  • N0 cell = verified session-21 nuisance tuple. N1 cell = that tuple crossed with frozen primary K8.
  • For each episode/cell draw exactly the observed count uniformly without replacement from eligible members. The observed set remains in the feasible universe.
  • Use 4,096 deterministic replicates plus the observation. Priorities use uint32-length-prefixed fields: domain, decoded contract digest, the common family N0-N1-common, scheme, big-endian uint32 replicate, episode ID and query ID. The null/design name is deliberately absent, so N0/N1/K12/K16 use common random numbers and differ only through their cells. The shared-query sensitivity omits episode ID entirely.
  • Lower-tail p-value: (1 + count(T_null <= T_observed))/4097; ties count against the claim.

Decision and robustness

  • Both N1 co-primary p-values must be ≤0.01.
  • Cohesion relative improvement must be at least 5%; specificity improvement at least 0.05 rank-percentile units; at least 60% of episodes must improve versus their null mean for each metric.
  • This is an intersection-union claim, so both co-primary alternatives must pass; no multiplicity discount is taken. N0 must agree in direction/effect but is not a rescue.
  • Use hash-even/odd episode splits, not query splits: int(episode_id,16)&1. Require both split effects to meet the practical threshold; no split p-value claim. This preserves each episode’s verified support.
  • Leave-one-episode-out effects are derived from the same replicate table; all 357 deletions must keep both effects positive, with no separate p-value fishing.
  • A shared-query-priority B2 sensitivity omits episode ID from the priority so a query’s priority is shared across episodes. Both cohesion and specificity effects must remain strictly positive under each of shared N0 and shared N1; this cannot rescue the episode-independent primary.
  • K12/K16, production total and market-context component are secondary. The two distance diagnostics retain one exact row for every frozen primary (episode_id, query_id) selected link, sorted by episode then query; require exactly 2,791 rows copied from the H1-bound top-20 cases. For each distance publish the raw-row digest, fixed-order math.fsum/count selected-link mean, and the equal-primary-episode mean of within-episode means. They have no null, p-value, decision gate or rescue role.
