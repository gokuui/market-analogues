What changed

The candidate stage now has versioned, vectorized views for coarse multichannel context, price shape, 12-stage development, candle/volatility, volume/shock, benchmark/relative movement, and structural drawdown/direction. Each view proposes local candidates; scale-incompatible distances are combined by stable ranks, never by an arbitrary raw weighted sum. Exact composite scoring remains the final authority.

Gate 09 Parquets explicitly mark the overlap-deduplicated oracle membership and rank. They also cache candidate-view distances with a version, allowing later fusion experiments to run in seconds while invalidating stale measurements after a view change.

Acceptance rule

A good average is insufficient. A gate passes only when every locked case clears its threshold, results are deterministic under row order and serial/parallel execution, the history gap and overlap rules hold, no instrument fails silently, the synthetic suite does not regress, and measured latency/RSS remain inside the declared budget. Calibration cases and final validation cases must be different.

Next implementation sequence

11A — Persisted, versioned view shards

Materialize each cheap view once per dataset, lookback, stride, symbol, and source fingerprint. Store columnar shards plus candidate IDs, cutoffs, quality tier, code/config hash, view version, and a completion manifest. Build atomically per symbol and support deterministic resume.

Tests: online-versus-shard distances agree within numeric tolerance; source or representation changes invalidate only affected shards; interruption and resume produce the same manifest and ranking digest; corrupt/missing shards fail visibly; serial and parallel builds agree.

Performance gate: a warm query scans ranks rather than raw OHLCV and meets NSE ≤120 s, NASDAQ ≤300 s, RSS ≤1 GiB.

11B — Exact-safe progressive scoring and pruning

Compute cheap exact components first and accumulate their non-negative weighted contribution as a formal lower bound. Add LB_Keogh or LB_Webb for the DTW term. Evaluate expensive components only when the bound can still beat the current constrained top-k threshold. Preserve overlap deduplication and per-instrument limits when maintaining that threshold.

Tests: pruned and brute-force searches return identical IDs, order, component values, and digest on every Gate 09 case; adversarial ties, missing benchmark context, constant paths, and overlap-heavy symbols are included; a deliberately invalid bound is caught by the synthetic verifier.

Performance gate: record candidates rejected at each bound, exact evaluations avoided, time, throughput, and RSS. Optimization is accepted only with bitwise-stable membership and tolerance-stable distances.

12 — Independent full-universe validation matrix

Lock new queries not used to choose pool 175: both markets, at least four symbols per market, 63/126/252 bars, historical and current cutoffs, different liquidity/stage regimes, and difficult missing-context cases. Use the exact-safe engine as the reference rather than a larger approximate pool.

Pass: ≥95% top-20 recall in every query for the fast path versus the exact-safe reference; zero future/overlap/quality failures; deterministic repeated and serial/parallel digests; NSE ≤120 s and NASDAQ ≤300 s for 252 bars; RSS ≤1 GiB.

13 — Operational hardening

Add checkpoint restart tests, artifact provenance, schema migration failure messages, disk-budget checks, and a single HTML run index linking every gate and report. Only after Gate 12 passes should multiview become the default search strategy.

Current decision

Continue development; do not declare the system complete. Gate 10 proves that the representation can form a high-recall bounded union on the stratified sampled oracle. Gate 11A has begun: the full NSE 252-bar persisted layer reduces warm candidate generation from 130.56 seconds to 13.63–15.54 seconds while using 442 MB disk. NASDAQ, other lookbacks, exact-rerank cost and exact-safe completeness remain open. Persisted shards and exact-safe pruning are the justified work; another hand-tuned approximate weighting is not.
