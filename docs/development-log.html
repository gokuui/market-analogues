L-001 — Standalone market-agnostic foundation

Why: Existing NASDAQ/NSE repositories are data providers, not a suitable home for a reusable analogue engine. Source data must remain read-only and derived artifacts isolated.

Verification: Adapter canonicalization, quality rules, scale invariance, causal episode boundaries, context alignment and report tests.

L-002 — Research and prior-art incorporation

Why: Reuse validated ideas and avoid rebuilding known methods without knowing their limitations.

L-011 — Gate 11B first exact-safe progressive scorer

What: Split exact representation scoring into a non-DTW lower-bound phase and a completion phase. Added a constraint-aware progressive scorer that orders candidates by the safe bound, maintains the current overlap/per-instrument-aware top-k threshold, and skips DTW only when a candidate cannot beat that threshold. Added an optional symmetric multivariate LB_Keogh bound inside the same Sakoe–Chiba band.

Why: Persisted candidate generation is now fast enough, but building representations and exact-reranking pool 1,000 remains the dominant end-to-end cost. All composite weights and component distances are non-negative, allowing a formal partial-sum lower bound without changing the metric.

Safety argument: The default bound includes every exact non-DTW component and 55% rigid price contribution; the omitted DTW contribution is bounded by zero. Candidates are processed in ascending lower-bound/episode-ID order. Once a future bound is strictly greater than the worst currently selected exact match, it cannot enter a full feasible top-k. Strict comparison preserves ties. Optional LB_Keogh sums per-point multichannel deviations outside the allowed envelope and divides by the maximum possible path length, remaining below normalized DTW.

Differential evidence: Synthetic family and overlap-heavy tests return identical IDs and distances for brute force, default pruning and stronger LB pruning. On current 252-bar oracle cases, default zero-DTW pruning returned identical rankings: NSE pruned 212/304 and reduced 3.30 to 2.38 seconds in the first run; NASDAQ pruned 120/224 and changed 3.44 to 3.26 seconds. The stronger LB version reduced exact DTWs to 60/304 on NSE and 94/224 on NASDAQ.

Rejected default: Eager/automatic LB_Keogh was not consistently faster. In a later concurrent run it improved NSE 3.35→2.07 seconds but slowed NASDAQ 2.47→2.92 seconds. It remains opt-in; the zero-DTW bound is the default until a measured policy justifies LB overhead.

Limits: This is a correctness-first implementation over an already materialized candidate list. It has not yet run differential checks over all 24 Gate 09 cases, does not avoid raw candidate representation construction, and is not yet wired into the user-facing search command.

L-014 — Constrained-pruning threshold correction

Finding: Planning an exhaustive Gate 12 reference exposed an adversarial case absent from the 24 sampled oracles. Suppose A and B initially fill top-2. A later, cheaper C overlaps both, so greedy overlap selection now contains only C and requires farther non-overlapping D. The scorer recomputed the selected set but retained the old A/B finite threshold when the set became incomplete; D could therefore be stopped even though it was required.

Fix: After every exact evaluation, set the bound threshold to the worst selected distance only when the constrained result contains top_k matches. If overlap deduplication or an instrument cap leaves fewer than top_k, reopen the threshold to infinity until the result is full again. This preserves the safe stopping proof: every candidate capable of changing the complete constrained prefix has been evaluated before a finite frontier can stop the scan.

Regression: Added the explicit A/B/C/D overlap topology. The old implementation would return only C; the corrected scorer evaluates D and returns C,D. This test is independent of financial feature values and directly exercises the control-flow invariant.

Gate 11B rerun: All 12 NSE and 12 NASDAQ exact-oracle cases still pass with maximum total delta 4.44e-16 and zero component delta. Work counts are unchanged: default prunes 2,147/3,192 NSE and 1,692/2,658 NASDAQ candidates; optional LB_Keogh prunes 2,411 and 1,817.

Gate 11C rerun: Schema-v3 RELIANCE digest remains 0badb2446edfcdaec2da97f6551324b8959c8583ad845511d3ca22aa3928ed4a; worst repeated time 29.05 s and peak 476.02 MB. AAPL remains 371e51e49ae7934bc8ae580b8439787fc67169c6dc344a143136bf053681e26c; worst 76.23 s and 772.26 MB. Both have zero repeat delta and the same 97/175 and 88/175 prune counts.
