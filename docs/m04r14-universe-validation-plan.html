Certified universe validation: no-look-back execution plan

This plan turns the four-case M04R-13 result into a system-level validation. Every task has a machine-verifiable completion gate. A failed gate is diagnosed and fixed on exposed data; untouched evidence is never silently resumed, retuned or relabelled.

Final goal: for any eligible OHLCV query, return the exact constrained historical top 20 with a reconstructible completeness certificate, stable latency/resource evidence, and an independently verified account of every query attempted or skipped. Retrieval correctness is not a claim of trading profitability.

1. Starting point and claim boundary

Proven

M04R-13 v2 exactly matches all 80 authority neighbours across the four known hard failures. Accounting and stock/benchmark causal prefixes match, every resource gate passes, and two independent verifier executions have the same deterministic digest.

Not yet proven

The new engine has not run across the other 56 M04R-11 queries, a fresh untouched cohort, concurrent service loads, a full current-symbol denominator, or a daily drift window. No real run exercised retained overflow or streamed threshold closure.

Explicitly out of scope

No current result proves future returns, profitable trades, complete historical exchange membership, delisting handling, corporate-action correctness, or NSE portability.

Data-date limitation: the available stock source ends on 2026-03-30, the benchmark extends to 2026-05-08, and the packed candidate generation is frozen at 2025-12-31. A new cohort can be cross-sectionally untouched using available data, but post-M04R-13 temporal generalization requires a later stock refresh and a rebuilt packed generation.

4. Untouched selection and sealing protocol

  1. Freeze seed, source lock, six-cell quotas, historical schedule, freshness/history/gap rules, all exclusions and issuer aliases before selection.
  2. Selection may use quality/liquidity data at the lock, benchmark and stock OHLCV only through each cutoff, and later timestamps solely to count the 60-session gap. It may not read forward values, setup labels, outcomes, previous candidates or authorities.
  3. Commit finished code/tests/verifiers as H0. Generate and independently verify the registry; commit only its binding as H1. Generate final preregistration; commit only that file as H2.
  4. The candidate producer accepts no authority argument and must seal all cases plus performance before any truth exists.
  5. A separate pre-open verifier reconstructs producer evidence. Then and only then atomically write/fsync RESULTS_OPENED.
  6. Build the exhaustive authority in a fresh isolated root, verify it independently, compare, and run a separate terminal verifier.

Failure policy: before any case-start marker, a mechanically proven zero-query-read launch failure may retry unchanged code in a new root. After any case starts, no resume or replacement. A semantic/source/Git/seal failure stops immediately and forbids authority construction. A timing failure may finish semantic evidence but still forbids truth opening. Any post-open failure is terminal; a repair can audit integrity only.

6. Immediate execution order

  1. Implement T14-00 and T14-01; do not launch 60 cases until every forced branch has oracle coverage.
  2. Run the bounded exact-worker/scheduler POC, select one primary lane, and freeze the exposed-60 contract.
  3. Execute and independently verify all 60 exposed cases. Use the results only for engineering/performance decisions.
  4. Freeze untouched SLOs and registry code. With available data, label the cohort cross-sectionally untouched; after a future refresh, repeat with a rebuilt pack for temporal generalization.
  5. Run the 72-case candidate-first untouched protocol, then proceed to the full eligible-universe shadow only if it passes.

Estimated development-60 runtime after implementation: 75–100 minutes for the primary serial lane, with a two-hour ceiling; a separate p8t1 throughput lane is expected to take roughly 20–35 minutes. These are planning estimates and will be replaced by raw measured distributions.
