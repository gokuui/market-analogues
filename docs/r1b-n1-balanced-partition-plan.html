R1-B N1 v3: non-degenerate, outcome-blind query-structure cells

Decision and reason

R1-B needs an N1 conditional null that preserves coarse query-chart structure in addition to the already verified nuisance cells. Diagnostic reconstruction found highly imbalanced farthest-first seed cells. Deterministic minimum-size merging correctly collapsed every K=8, 12 and 16 option to one sealed final cell, making N1 identical to N0.

Frozen response: v2 remains immutable. V3 changes only the outcome-blind structure partition and its support assessment. It does not open R1-B cohesion/specificity statistics, neighbor outcomes, forward returns, labels, prediction or trading rules.

Inputs and leakage boundary

  • Use exactly the same 3,270 registered query identities in canonical query-ID order and the same independently verified 141-value market-excluded query vector, in this exact order: coarse[0:96], then stage.astype(float64).reshape(12,4,order='C')[:,0:3].ravel(order='C'), then structural[0:9]. No additional weight, whitening or block normalization is permitted.
  • Reuse the verified session-21 N0 nuisance cells and the frozen recurrent cohort of 369 episodes / 2,865 links. Do not change retrieval or select a new cohort.
  • Partition construction may not read benchmark/relative feature channels, candidate identities, eligibility memberships, selected-neighbor memberships, inbound counts, ranks, distances, R1-B statistics, outcomes or future values.
  • Support computation may read only query-cell labels, causal eligibility and observed membership. It must finish and be sealed before any R1-B statistic is implemented or opened.

Deterministic balanced recursive rank-PCA algorithm

  1. Rank transform: require a finite float64 matrix of shape (3,270,141) and unique ordered IDs. Within feature j, canonical float64 values compare by exact numerical equality. For 1-based ordered positions a..b, persist doubled midrank m=a+b and compute z=(m-(N+1))/(N-1). Endpoints are -1/+1, all-tied columns are +0.0, and -0.0 is normalized to +0.0. Query ID never enters tie-group formation.
  2. Recursive target allocation: for requested K in {8,12,16}, begin with all queries and target K leaves. At a node with n rows and k target leaves, assign kL=floor(k/2), kR=k-kL and nL=floor(n×kL/k); nR=n-nL. This fixes balanced final leaf sizes.
  3. Local axis: form Zc=Z[I]-column_mean(Z[I]) in fixed row/column order and scatter S=Zc.T@Zc. A symmetric float64 eigensolver runs under a one-thread BLAS limit in the sealed NumPy/LAPACK runtime. With λ1≥λ2, use relative gap (λ1-λ2)/λ1. Orient the leading loading at the lowest original feature index attaining the exact maximum absolute loading; make that pivot positive.
  4. Degeneracy fallback: if relative gap ≤1e-10, select the original feature maximizing the exact integer quantity n×sum(m²)-sum(m)² inside that node; ties use the lowest feature index and the axis is +e_j. If λ1≤0, every exact variance is zero, the solver is non-finite/nonconvergent, or any node fails, that requested K fails closed with no retry, merge, alternative axis, reuse or coarsening.
  5. Exact split: compute every projection with math.fsum in fixed feature-index order, then order by projection and query ID. Query ID may resolve an exact bitwise-equal boundary only. Otherwise require pR-pL > 1e-10×max(1,max|p|); a smaller positive margin makes that K numerically unresolved.
  6. Recurse locally: require n≥k, use root path empty, append 0/1 for left/right, and label terminal paths in lexicographic order. A node failure invalidates only its requested K. Expected size multisets are K8: 6×409 + 2×408; K12: 6×273 + 6×272; K16: 6×205 + 10×204.

This construction guarantees non-empty, nearly equal-sized leaves by design while allowing the shape-derived axis to change locally. It avoids the outlier-medoid collapse without using downstream retrieval behavior to manufacture clusters.

Encoding and runtime: canonical JSON is UTF-8 with sorted keys, compact separators and no NaN. Ordered IDs and integer midranks use canonical JSON digests. Float arrays use shape-prefixed contiguous little-endian float64 bytes; reported scalar floats use float.hex(). Exact byte identity is claimed only in the sealed NumPy/LAPACK/runtime environment; final query memberships must always agree exactly.

Gates before selection

  • For each K, retain exactly K labels; each label is used; every query appears exactly once; leaf sizes are only floor(3,270/K) or ceil(3,270/K).
  • The crossed N1 cells must have more distinct cells than the 71 session-21 base cells; every global label must appear and contribute at least one crossed cell. No merge is allowed. Do not add post-view silhouette, entropy, compactness, explained-variance or distance gates.
  • One-worker and 12-worker causal-vector reconstruction must produce identical transformed, membership and node digests; PCA itself remains single-threaded.
  • An independent implementation must reconstruct midranks, every recursive split, memberships, support counts, artifacts and HTML from the sealed inputs.
  • At least 90% of the 369 episodes and 90% of the 2,865 links must retain support of at least 4,096 matched sets after crossing session-21 N0 with the structure label.

Primary decision: K=8 is the sole primary N1 because it is the coarsest non-degenerate control with maximum expected support. K12 and K16 are secondary sensitivity analyses and cannot rescue or change the primary. K8 failure yields unresolved; do not relax thresholds or inspect R1-B statistics.

Exact support: for episode e, compute the product over crossed cells c of C(A_ec,Q_ec), saturated at 4,096; observed Qe must be a duplicate-free subset of Ae. Episode coverage denominator is fixed at 369 and link coverage weights the frozen inbound counts totaling 2,865. Evaluate all declared K even if one fails; never early-stop.

Implementation and verification sequence

  1. Implement the pure rank transform and recursive partition with synthetic fixtures covering exact ties, constants, repeated eigenvalues, sign ambiguity, odd n/k allocation and all-constant refusal.
  2. Before H1, use synthetic fixtures only. Differentially test vector-worker order, ties, constants, repeated eigenvalues, sign ambiguity, odd n/k allocation, boundary instability and all-constant refusal.
  3. Implement separate partition and support executables, then commit implementation/tests as H0. Generate and commit a sole-child H1 preregistration binding both runtimes, exact solver environment, canonical JSON/digest rules, inputs, K roles, gates, failure states and claim boundary.
  4. After H1, the partition executable receives only the sealed query registry and causal OHLCV/representation inputs—no candidate, eligibility or Qe path—and publishes a create-only partition artifact. Only after that publication may the separate support executable open eligibility/Qe and cross the frozen N0 cells.
  5. Commit a separate verifier, run the independent reconstruction and record both producer and verifier digests in the development log.
  6. The producer publishes partition_invalid, reproducibility_failed, support_inadequate or support_pass_pending_independent_verification; absence is never used to represent failure. Only the separate verifier may issue verified_support_pass. Verified K8 support permits freezing the still-separate B2 statistic/shared-priority contract; it does not authorize B2 execution, prediction or labels.

Alternatives deliberately not selected

  • Farthest-first or k-means: outlier seeds can create tiny cells; retries or seed searches invite post-result discretion.
  • A single global PCA grid: deterministic but can leave sparse/empty intersections and wastes support.
  • Quantile bins on hand-picked features: balanced but imposes an unearned manual definition of chart structure.
  • Cross-fitting: useful as a later sensitivity analysis, but it does not repair a one-cell partition and would reduce already finite conditional support.
  • Outcome- or retrieval-aware clustering: forbidden because it would tune N1 to the statistic it is supposed to test.
