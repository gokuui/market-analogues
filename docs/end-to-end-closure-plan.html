End-to-end closure plan

Truthful boundary

NASDAQ retrieval, causal outcomes and evidence cards exist, but the first walk-forward composite did not outperform its important baselines and the separate 4% post-signal study did not authorize a predictive feature. End-to-end closure produces a robust research/evidence system—not a buy/sell claim.

E2E-02 — Cross-adapter synthetic certification PASS

Run identical deterministic OHLCV through directory-Parquet, directory-CSV, long-table-Parquet and long-table-CSV configurations. Compare canonical bars, query identity, ordered neighbours, component distances, evidence summaries and HTML claims.

Result: all four routes agree; same-format identities are exact and the largest CSV/Parquet numeric delta is 4.551914400963142e-15. Inputs are unchanged, reports validate, and future mutation cannot affect retrieval.

E2E-03 — Real NSE replay FRESH AUTHORITIES REQUIRED

Use the existing read-only loser/data/validated source and NIFTY benchmark. The old 252-session authorities cannot certify the current runtime because their whole-file benchmark lock drifted and their coarse-distance arithmetic predates a float64 correction. Build a new 12-case full-universe matrix over a semantic prefix lock, then carry its exact results through outcomes and reports.

Pass: all 12 current/historical × A/B × low/middle/high cases have current-code exact top-20 certificates; current benchmark prefix is bound; no temporal/overlap violations; repeated digests are stable; source appends cannot alter the frozen prefix; reports preserve censored/missing outcomes.

E2E-04 — Operational and performance certificate

Exercise clean start, interrupted publication, resume, corrupt artifact refusal and repeated search. Use the available 12 cores where the verified implementation benefits, while measuring wall time, CPU use, peak RSS and disk use rather than imposing obsolete low-memory assumptions.

Pass: identical semantic results across restart and concurrency; atomic outputs; actionable failures; resource results reported honestly.

E2E-05 — Release snapshot

Run the complete regression suite, parse every tracked HTML document, check repository integrity, publish a single status index, update reproduction commands and commit a clean release checkpoint.

Pass: zero failing tests, clean worktree, all required evidence linked, and limitations state that predictive value is not established.

Only after closure: MCP-assisted improvement cycle

Inventory the available MCP data/research systems, record what each can contribute, and use them to find representations, retrieval algorithms and evaluation designs similar to this project. Each adopted idea receives a small outcome-blind POC first, then a preregistered walk-forward comparison against unconditional, recent-return/volatility, price-only and current-composite baselines. Ideas are adopted only on measured improvement; the final period is not reused for tuning.
